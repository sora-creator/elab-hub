# Assignment Edit Policy

## 미시작

- 제목과 마감일 수정 가능
- 힌트와 읽기 도움 수정 가능
- 문장 추가, 제외, 교체, 순서 변경 가능
- 문장 구성이 바뀌면 기존 SentenceSet을 덮어쓰지 않고 새 set key로 저장한 뒤 Assignment가 새 세트를 가리키게 한다.

## 진행 중 또는 완료

- 제목과 마감일만 수정 가능
- 힌트, 읽기 도움, 문장 목록과 순서는 잠근다.
- UI 잠금과 별개로 서버가 Attempt/Target 상태를 다시 검사한다.
- 학생 풀이를 무효화하는 삭제/취소 기능은 이번 범위에 추가하지 않는다.
