🧩 끊어읽기 · 주어동사찾기

폴더에 지문을 모아두고, 번호를 눌러 바로 열어서 끊어읽기와 주어·동사 표시를 같이 할 수 있어요.

📁 폴더

JSON 가져오기: {folderName, passages:[{num,text,image?}]} 형태의 파일을 통째로 불러와 폴더+지문을 한 번에 만들어요. image는 도표·네모칸처럼 텍스트로 옮기기 힘든 부분을 참고용으로 같이 보여줄 때만 넣으면 돼요(끊어읽기/색칠은 여전히 텍스트에서만 동작).

아직 폴더가 없어요. "+ 새 폴더"로 하나 만들어보세요 (예: 고2 25년 9월 모의고사)

📑 문항

아직 지문이 없어요. "+ 지문 추가"로 18번부터 순서대로 넣어보세요.

단어 사이를 클릭하면 끊어읽기 / 표시가 생겨요. 단어 자체를 클릭/드래그하면 위에서 고른 색으로 칠해져요(같은 색으로 다시 칠하면 지워짐).
