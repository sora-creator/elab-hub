🔍 문법학습 · 교사

모의고사 PDF를 넣으면, 분사구문 / to부정사가 쓰인 문장만 뽑아드려요. 설치 없이 이 화면에서 바로 됩니다.

🎯 문법 문장 찾기: 구문분석기(spaCy) + 정규식(regex) 병행 — 더 정확해요

분사구문/to부정사/관계사절/수동태/동명사/명사절은 진짜 문장 구조를 분석하는 구문분석기(spaCy)로 판별하고, 나머지(비교구문/도치/가정법/강조구문/조동사+완료)는 패턴이 단순해서 정규식을 그대로 씁니다. 게다가 같은 문장을 정규식으로도 한 번 더 돌려서 spaCy와 판정이 갈리는 경우 ⚠️ 배지로 표시해줘요(아래 "① 정확한 태깅 결과 가져오기" 참고). 정확도가 가장 중요할 땐 이 방법을 쓰세요.
  1. grammar/mockexam_db/grammar_gui.pyw를 더블클릭해서 도구 창 열기
  2. "① PDF 분석 (spaCy)" 탭에서 PDF를 선택 (파일명에서 연/월/학년 자동 인식) → "분석해서 저장하기" 클릭
  3. 분석이 끝나면 PDF 옆에 생긴 JSON 파일을 아래에서 선택
이렇게 가져온 회차는 목록에 🎯 spaCy 배지가 붙어요. (같은 도구의 "② Claude 검증" 탭으로 판정 불일치 문장을 추가로 검증할 수도 있어요.)

1 정확한 태깅 결과 가져오기

파이썬 CLI(export_json.py)로 spaCy 기반 태깅을 미리 돌려서 만든 JSON 파일을 불러와요. 이렇게 가져온 문장은 가져온 시점의 태그로 고정돼요 — 나중에 문법 규칙이 추가되면 파이썬에서 다시 내보내 재가져오기 해야 반영돼요.

⚙️ 설정 (학생 공유용 백엔드)

시험보기 모듈과 같은 구글시트 웹훅 주소를 등록하면, 여기서 찾은 문장을 학생에게 공유 링크로 보낼 수 있어요.

📥 공유했던 세트 목록 · 영상 링크

학생에게 공유한 문법 세트예요. 강의영상을 나중에 찍어 유튜브에 올리면, 여기서 링크만 붙여 저장하세요 — 학생이 이미 갖고 있는 공유 링크에 자동으로 영상이 떠요(다시 공유 안 해도 됨).
새로고침을 눌러주세요.

📝 제출현황 (해석 · 끊어읽기)

학생이 제출한 해석과 끊어읽기 결과예요. 채점은 안 돼 있어요 — 끊어읽기의 "정답 비교"만 참고용으로 표시되고, 이 화면은 교사만 봐요(학생 화면엔 절대 안 나가요).
세트를 선택하고 "불러오기"를 눌러주세요.

✅ 최종본 업로드

"📋 구분문제 PPT 다운로드"로 받은 파일을 파워포인트/구글슬라이드에서 검토하고 (필요하면 슬라이드를 통째로 삭제하거나 문장을 고친 뒤) 그 최종본을 여기 올리세요. 학생은 단어테스트와 같은 형식의 객관식 시험으로 이걸 풀게 됩니다. 원본 pptx 파일은 저장하지 않고, 그 안의 문제 내용(문장·밑줄·보기·정답)만 추출해서 저장해요. 아래에서 ✅ 표시된(선택된) 폴더 안에 업로드돼요 — 폴더 이름을 클릭해서 바꿀 수 있어요.
📄 여기(또는 페이지 아무 곳)에 pptx 파일을 끌어다 놓거나 클릭해서 선택하세요 — 여러 개 한 번에 가능

📁 폴더 · 최종본

폴더와 최종본이 한 화면에 같이 나와요. 폴더 이름을 클릭하면 그 폴더가 ✅ 선택되어 업로드/새 폴더 대상이 바뀌고, "이동" 버튼으로 폴더·최종본 위치를 자유롭게 옮길 수 있어요. "학생 링크 복사"로 만든 링크를 teacher/students.html의 학생별 배정 화면 "✅ 구분문제 최종본" 칸에 붙여넣으면, 그 학생의 접속 포털에 시험 카드로 떠요.
새로고침을 눌러주세요.
